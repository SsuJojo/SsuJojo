## 我在意的工程习惯 · Engineering principles

- 先做出可用闭环，再逐步提高可靠性。
- 用真实数据和真实流程验证功能，不用演示数据掩盖空状态。
- 把配置、错误处理、权限和部署写进项目，而不是只留在脑中。
- 用小步提交、测试和 CI，让每次改动都能被复查。
- 对不再维护的项目明确标注状态，避免误导使用者。
